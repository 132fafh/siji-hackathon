## 真实案例

`cases/` 包含量子电网研究的结构化路径与语义恢复评测题，用于检验 AI 是否保持用户原意、证据状态和研究边界。案例是研究总结，不是逐键行为数据。

星落与会话结构测试统一优先使用 `../tests/fixtures/delidata-wason-constructive.json`：它转录 DeliData 论文附录 Table 12 的 15 条公开发言，保留原文与论文角色标注；`expectedStarfall` 是本项目的人工测试预期，不是论文原始标注。该案例不用于遗忘概率、停顿建模或中文分词准确率评估。

## 遗忘基线

`baseline/` 为无依赖训练与合成测试脚本；`baseline/out/` 为真实 Duolingo HLR 抽样数据上的结果。

抽样：257,085 条；训练 205,844，测试 51,241，按用户隔离。

| 模型 | Test logloss | Test Brier | Test AUC |
|---|---:|---:|---:|
| 常数 | 0.314246 | 0.050740 | 0.500000 |
| 指数 | 0.314056 | 0.050710 | 0.530993 |
| 幂律 | 0.313751 | 0.050654 | 0.530993 |
| Weibull | 0.326120 | 0.053037 | 0.530993 |
| 原始 HLR | 0.598198 | 0.070571 | 0.544768 |
| 带初始回忆率的 HLR | 0.313311 | 0.050602 | 0.557447 |

原始 HLR 的 `p(0)=1` 与 session 比例数据不匹配，保留为失败对照。带初始回忆率的扩展表现最好，但时间信号弱、提升有限，不能据此宣称思迹场景的高精度预测。

原始 379MB 数据与 19MB 抽样文件不包含在交付包内。下载和预处理脚本位于研究根目录。
