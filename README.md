# 思迹 · 黑客松完整项目

一个可离线演示的完整链路：

```text
Kimi 页面输入
→ 插件融合行为与对话上下文
→ 活跃度/回忆辅助评分下降
→ GitHub 风格弹窗
→ 用户主动选择进入思迹
→ 草稿成为不可覆盖的原始表达
→ 思迹继续澄清与留痕
```

## 快速运行

### 1. 启动思迹与演示后端

需要 Node.js 18+，无需安装依赖：

```bash
cd D:\Kimi\siji-hackathon
node server/server.js
```

打开：

- 思迹：http://localhost:8141/
- Kimi 模拟页：http://localhost:8141/mock-kimi.html
- 健康检查：http://localhost:8141/api/health

### 2. 加载插件

1. 在 Edge 打开 `edge://extensions/`（Chrome 则为 `chrome://extensions/`）；
2. 开启“开发人员模式”；
3. 选择“加载解压缩的扩展”；
4. 选择 `D:\Kimi\siji-hackathon\extension`；
5. 回到模拟页，输入一段文字并停顿约 10 秒；
6. 在弹窗中点击“进入思迹”。

草稿通过扩展本地存储一次性交接，不写入 URL。接收后删除临时载荷。

## 插件功能

- 输入、停顿、退格、重写、回读、焦点和草稿上下文采集；
- 可解释的行为与上下文融合评分；
- 少打扰、标准、较灵敏、关闭、阈值和冷却控制；
- 小型自适应批准框：桌面约 312px、移动端不超过 340px，默认只显示简短说明、批准和取消；原因、SVG 曲线和灵敏度设置收进可展开详情；
- 一键携带草稿进入思迹；
- 跨站点适配器覆盖主流 AI 页面，未知站点可通过扩展按钮手动启用；支持范围、权限和适配限制见 `extension/SUPPORTS.md`，比赛交付清单见 `SUBMISSION.md`。

**评分是演示用的上下文启发式分数，不是经过验证的真实遗忘概率，也不代表插件能读取思想。**

已在当前真实 `kimi.com` 页面验证 `contenteditable` 输入框、弹窗与草稿交接；若后续页面 DOM 更新导致输入框未识别，请按 `extension/README.md` 的选择器说明适配。

## 光影气泡页

打开 **http://localhost:8141/#/light**：

- 原生 WebGL 逐像素颜色场：每个像素由坐标和时间共同决定颜色，整个环境连续流动，不是色带移动；
- 桌面 12 个、移动端 8 个透明气泡随光场漂移，中央保留一个较大的“当前想法”气泡；
- 触点会改变局部光场：移动跟随、点击光圈、长按聚集能量，并使用 spring/阻尼形成自然惯性；
- 环境具有安静、呼吸、回应和释放的非均匀节奏；选中气泡后周围自然退场，文字按背景亮度自动选择深浅色；
- 戳破采用吸光、粒子消散和新词淡入转场，退出气泡仅在靠近或聚焦时清晰；
- 节点改为不规则星点，具有独立星形、亮核和呼吸透明度；相近想法形成缓慢移动的星落/星座，连线带柔和流光；
- 采用极简黑底留白设计：少量细边圆点，主节点约 90–110px，文字仅在悬浮、选中或聚焦时显示，移除大星星、星芒、流星和复杂连线；
- 星点改为柔和亮核与细腻衍射星芒，背景使用银白/冷白极光缓慢浮动，不使用彩色色块；
- 背景接入简化二维点涡流场与半拉格朗日颜色平流，形成青蓝、洋红的柔和旋转星云拖尾和 Bloom 弥散辉光；按住并拖动空白会沿轨迹生成较弱涡元，单击空白不生成，点击节点仍进入导图；
- 文字默认清晰可见：桌面约 15–16px、移动端约 13–14px，不再依赖靠近才能阅读；
- 采用极简黑底留白设计：少量细边圆点，主节点约 90–110px，文字仅在悬浮、选中或聚焦时显示，移除大星星、星芒、流星和复杂连线；
- 中央星核增加多尺度星芒，少量斜向流星余晖缓慢划过；
- 双击节点或按 Ctrl/⌘+Enter 可编辑关键词与补充想法，保存为可编辑扩展数据，不修改 original 原始表达；悬浮、聚焦或触摸节点可查看来源片段、频次和收束说明；
- 气泡与环境共享动态颜色系统：虚词为低饱和蓝灰，内容词为青绿/蓝紫，疑问和方向词使用少量暖色；
- 词间启发式收束度由共现、词汇重叠、共现图连接和主题连续性计算，高收束时气泡由暗色转向明亮暖象牙色，不用于证明真实逻辑；
- 每个气泡拥有独立且可复现的极慢移动函数，连续正弦漂移与平滑随机游走结合，性质相近的气泡共享流动分量；
- 所有气泡支持真实拖拽：8px 阈值区分点击与拖动，松手后小幅惯性并回到慢速流动；空间邻近关系会连续影响收束显示色；
- 桌面气泡尺寸自适应放大；环境改为近纯黑底与大小不一的稀疏柔光斑，光斑具有宽光晕、极慢连续漂移和独立轻微呼吸，不显示奶白底色、浓彩色块或规则波纹；
- 想法按性质与共现形成 2–4 个非规则肥皂泡群，使用薄膜连线、聚簇排斥布局和群组慢速流动，拖出距离后自然分开；
- 背景算法参考 MIT 许可的 Aurora 项目，完整版权说明位于 `app/licenses/aurora-MIT.txt`；
- 长按先出现细裂纹，随后父气泡分裂为 2–3 个真实小气泡，各自向外缓动、轻微旋转并恢复慢速流动；
- 少量微光拥有独立出生、呼吸、衰减和再生周期，近距微光之间出现柔和连丝，触点仅轻轻唤醒并留下缓慢余辉；
- 气泡大小表示短句在当前用户语料中的相对出现频次，不表示遗忘概率；
- 长按约 650ms 戳破后，父气泡分裂为 2–3 个更小的共现或候选子气泡，可继续递归分裂；共现只表示出现在同一用户消息中，不作为语义证明；
- 废弃、过小及溢出气泡进入左下角灰色语料箱，可查看并恢复；
- 星点文字由本地规则从用户原话中截取完整短句，主持、同意、礼貌用语和单独虚词不成星，不混入 AI 内容；
- 点击星点打开局部思维导图，Enter 也可打开；Shift+Enter 或长按空格戳破；
- 提供键盘焦点、扩大后的移动触控热区、边缘文字防裁切及减少动态效果支持。

## 星落与局部思维导图

- 点击任意星点打开以其为中心的无框有机网络，不使用固定列、卡片层级或常驻侧栏；节点有斥力、弹性曲线和缓慢漂移，可拖动节点、平移和缩放网络；
- 默认只显示思维网络与角落退出点，不渲染顶部栏、关键词条、参量条、底部操作条或其他常驻框架；扩展、接受、拒绝、修改、原话和偏好全部收进节点右键/长按菜单，Shift+F10 也可打开；
- 自动舒展只调整布局，不自动生成内容；新分支从父节点周围涌现，原话与偏好仅按需出现；
- 节点分为概念、想法、疑问、依据、前提与边界、方向、结论、片段八类，不同类型提供不同扩展权限；片段默认不由 AI 补全；
- 支持向后推演、向下细化、横向扩展、向前追因、反向检查，均通过节点菜单操作；
- 每次生成 1–3 条候选，虚线表示待确认；可接受、修改后接受、拒绝、恢复，AI 来源始终保留，原始表达不变；
- 全图与响应内候选会去重，反复扩展不返回旧内容，候选池耗尽时提示已有路径；引用父节点文字不视为重复，数字与否定差异受保护；
- 扩展偏好使用七个显式数值维度及表达风格、候选数量，只根据当前会话的可见反馈调整排序；可直接编辑、重置，不建立固定人格画像；
- 导图与偏好保存在当前会话 localStorage，刷新后恢复；Markdown 导出包含节点、关系、AI 来源、接受/拒绝状态和偏好说明；
- 没有真实 API 时，`/api/expand` 只返回明确标注的本地结构化提示，不宣称真实 AI 语义扩展。

## DeliData 公开会话演示

打开 **http://localhost:8141/#/demo/delidata**，直接查看网上查得的 [DeliData 附录 Table 12](https://arxiv.org/html/2108.05271v3) 原始会话。前端读取 `app/demo-data/delidata-wason-constructive.json`，保留 15 条英文发言、发言人、顺序和论文来源，不使用用户会话，也不虚构演示关键词。

公开案例以 `demoPublicCase` 标识为只读，节点显示“DeliData 公开原话”，不会写入 localStorage 历史；扩展与偏好只在内存中演示。没有本地会话时，`#/light` 也回退到该公开案例。

## 全图关键词与聚焦模型

`app/js/graph-keywords.js` 在本地运行可解释的组合模型：

1. **TextRank**：按节点内词语共现建图，用邻居的出边总权重迭代词语分数，并保留连通分量大小；过滤发言人、虚词、通用词和残缺词；
2. **个性化 PageRank**：以当前节点为种子计算结构中心性，原话、已接受路径、AI 候选和共现使用不同权重，共现不冒充逻辑；
3. **MMR**：用 `λ relevance - (1-λ) maxSimilarity` 逐步选择关键词、节点和实际扩展候选，降低重复内容。

原界面通过 `app/js/graph-expansion.js` 把当前逻辑链、TextRank、个性化 PageRank、MMR、偏好向量和重复拦截接入每次扩展。扩展偏好提供表达方向、每次候选数量与 **边界扩张总率上限（100%–500%）**。上限按原始边界节点换算为候选预算，已接受节点计入当前比例，待确认节点预留额度，拒绝后释放；达到上限或暂停时均不请求模型。默认每次 2 条、总率上限 500%。这些是扩展规模控制，不是遗忘概率或心理测量。

新候选从父节点附近逐渐展开，已有节点保持位置并缓慢避让；视角只在候选可能离开可视区域时平滑跟随。减少动态效果设置下直接呈现稳定布局。

历史验证脚本和研究指标仅作内部开发资料归档，不是产品页面，也不进入用户导出的思考记录。

参考：[TextRank（EMNLP 2004）](https://aclanthology.org/W04-3252/)、[MMR（SIGIR 1998）](https://dl.acm.org/doi/10.1145/290941.291025)、[KeyBERT](https://maartengr.github.io/KeyBERT/)、[图美学与理解](https://doi.org/10.1007/3-540-63938-1_67)、[心理地图保持](https://www.mdpi.com/2076-3417/11/10/4336)。当前实现是字面与结构启发式，不是训练好的语义模型；后续可用嵌入向量替换字面相似度，但需要独立评测。

## 后端 API

- `GET /api/health`
- `POST /api/restate`
- `POST /api/hints`
- `POST /api/expand`
- `POST /api/recall`
- `POST /api/answer`

**未配置 `SIJI_API_KEY` 时，全部仍明确标注为演示模式。** 可通过服务端环境变量启用 OpenAI 兼容的真实模型：

```bash
export SIJI_API_BASE="https://api.openai.com/v1"
export SIJI_API_KEY="在本机环境填写"
export SIJI_MODEL="gpt-4o-mini"
export SIJI_TIMEOUT_MS="15000"
node server/server.js
```

`SIJI_API_BASE`、`SIJI_MODEL`、`SIJI_TIMEOUT_MS` 可省略，默认值分别为 `https://api.openai.com/v1`、`gpt-4o-mini`、`15000`。密钥只留在后端环境，不写入前端、扩展或日志。配置真实 API 后，必要文本会发送给对应服务商；调用失败会自动回退 demo，响应的 `meta.actualMode / fallback / reason` 标明实际来源和回退原因。详见 `server/README.md`。

`recall` 始终由本地规则优先确定带消息 ID 的原文证据，模型不能改写或伪造来源；AI 推测单列。找不到依据时明确返回不确定，不编造恢复内容。

## 边界

- 插件与后端演示均已实现，但真实断片检测模型尚未训练；
- 星点短句和演示扩展是本地启发式，不是大模型语义理解；真实外部 AI 尚未实际调用，只通过本地 mock 验证成功路径；
- 偏好向量是显式交互权重，不是语义嵌入模型，也不是人格或遗忘概率；
- 公开 Duolingo 基线只用于验证遗忘建模流程，不是思迹用户数据；
- 不把停顿直接等同遗忘，不把弹窗分数当成科学概率；
- 原始表达不会被 AI 覆盖；
- 用户始终可以拒绝、关闭、返回或离开。
